# 重生之粟牙在江湖救急

这是 [jynew](https://github.com/jynew/jynew) 样例模组《渡城残魂传》的改动，路径与原工程一致。把 `jyx2/Assets/Mods/SAMPLE` 覆盖回游戏工程后，在 Unity 里打开该模组的 `ModSetting`，点击「生成配置表」，再进入模组。

- 作品名：重生之粟牙在江湖救急
- 主人公：粟牙。开局姓名、人物表和对话里原来的「陶六一」都改成这个名字
- 武器：八尺戒尺。开局就装备，主角不能换成别的武器，别人也不能拿走
- 回复生命：只有药瓶「和天下」能回复生命，其他伤药不再回复生命
- 技能：样例模组里的武学全部改成高中物理相关技能，战斗中会显示技能名
